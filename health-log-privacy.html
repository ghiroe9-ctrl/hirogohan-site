hiro-health-log プライバシーポリシー

「hiro-health-log」（以下「本アプリ」）は、ひろごはん運営者が自分自身の健康記録を整理するために作成した個人用のツールです。一般の方への提供は行っていません。

取得するデータ

本アプリは、利用者本人の許可を得たうえで、Google Health API から次のデータを読み取ります。

  • 睡眠（就寝・起床時刻、睡眠ステージ）
  • アクティビティ（歩数）
  • 体の測定値（体重、体脂肪率）

読み取りのみを行い、Google Health 上のデータを変更・削除することはありません。

データの利用目的と保存先

取得したデータは、利用者本人の Google カレンダー（睡眠の記録）と Google スプレッドシート（日ごとの記録）に書き込むためだけに使用します。データは利用者本人の Google アカウント内にのみ保存され、運営者のサーバーや第三者のサービスに送信・保存することはありません。

第三者への提供

取得したデータを第三者に提供・販売することはありません。広告や機械学習モデルの学習に利用することもありません。

本アプリによる Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に準拠します。

アクセスの取り消し

利用者は、Google アカウントのサードパーティ アクセス設定から、いつでも本アプリへのアクセス許可を取り消すことができます。
